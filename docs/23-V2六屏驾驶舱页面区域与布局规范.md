## 一、架构总览

MOD V2 驾驶舱采用**六屏架构**，全面覆盖管理、建设、推广、运营、风险与研判全生命周期。为确保产品设计、前端开发、独立 QA 和复审角色在沟通中的定位精准无歧义，系统设立了**全局唯一且稳定的区域定位编号（Zone Locator Code）**。

### 核心规范要求：
1. **双重呈现**：区域编号必须同时作为前端 DOM 的 `data-zone` 属性（如 `data-zone="A3"`）和界面上可见的小型标签（`<span class="zone-badge">A3</span>`）。
2. **标题保留**：区域编号仅作为产品坐标，**严禁替代业务标题**。
3. **数据一致**：全部六屏直接消费 V2 只读 API（`/api/v2/...`）或已对齐的脱机基线快照（`v2-sim-snapshot.json`），数据总量保持 1,685,923 条真实模拟记录。

## 四、DOM 定位与 CSS 标记规则

1. **DOM 属性规范**：
   ```html
   <section class="panel" data-zone="A4">
     <div class="panel-head-left">
       <span class="zone-badge">A4</span>
       <span class="panel-eyebrow">CONSTRUCTION</span>
       <h3>核心建设进度</h3>
     </div>
     ...
   </section>
   ```
2. **样式规范**：
   - 徽章使用统一青色发光科技感样式（`#00d2ff`，半透明青色背景，`1px solid rgba(0,210,255,0.4)`）。
   - 地图与特殊卡片在右上角或左上角悬浮标注。
