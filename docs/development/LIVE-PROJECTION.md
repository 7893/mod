# 驾驶舱只读实时投影

更新日期：2026-09-04
状态：现行
适用范围：驾驶舱演示动态、实时事件接口和增长展示约束

## 目的与边界

实时投影让持续开启的驾驶舱以不规则节奏显示单据、凭证和集成增量。它只维护进程内展示状态，
不创建数据库连接、不写业务表，也不启用 `business_simulator.py` 或历史协作状态机。

页面必须显示“演示动态”标识。投影数字不是持久化业务事实；真实快照始终是基数和事实来源。

## 数据流

```text
真实只读快照 -> 进程内投影调度器 -> SSE -> 前端投影增量 -> AnimatedNumber
```

- `/api/v2/dashboard/snapshot` 继续按原周期提供真实基数。
- `/api/v2/live-projection/events` 向所有在线大屏广播同一事件时间线。
- `/api/v2/live-projection/status` 提供不产生事件的只读诊断状态。
- 浏览器将快照基数和服务端累计投影分开保存，不修改快照对象。
- 服务端重启会生成新的 `projection_id`，浏览器据此清零旧投影并采用新状态。

## 增长约束

- 到达间隔采用有上下界的随机分布，不按固定周期增加相同数量。
- 活跃度按展示时区（`MOD_DISPLAY_TIMEZONE`，默认 `Asia/Hong_Kong`）的小时、工作日和月内阶段调整；
  上午和下午高于午休、夜间和周末。展示时区的唯一定义在 `backend/app/config.py`，本模块不得另行写死。
- 单次单据最多 3 笔，凭证和集成最多 2 条；每日单据投影有硬上限。
- 事件遵循单据、凭证、集成顺序，凭证累计量不得超过投影单据量，集成累计量不得超过投影凭证量。
- SSE 只承载服务端生成的共同事件，禁止浏览器独立随机修改累计值。
- 队列有容量上限，慢客户端只保留较新的展示事件；重连时先接收服务端累计状态。

当前阶段不使用历史硬编码的 2027-03-01 目标值。长期目标曲线必须先根据当前数据库基线和新的业务目标
重新确认，之后才能作为可配置速率因子加入本投影。

## 配置与运行

`MOD_LIVE_PROJECTION_ENABLED` 默认为 `true`，设置为 `false` 可停止事件生成。该开关与
`MOD_SIMULATOR_ENABLED` 完全独立；关闭或开启实时投影都不会改变写库模拟器的安全门禁。

多进程或多实例部署前，必须把广播状态迁移到共享消息设施，保证各实例事件一致。现行单进程部署使用
内存广播即可。生产部署仍需遵守 [USA 部署目录规范](../operations/USA-DEPLOYMENT-LAYOUT.md)。
