# 数据与安全规范

更新日期：2026-09-02
状态：现行
适用范围：数据资产、数据库、环境配置、日志、远端部署和外部平台

## 数据分级

- 可提交：维护源码、脱敏文档、测试夹具和安全示例配置。
- 本地资产：生成 CSV/JSONL、参考材料、历史归档、构建结果和 CLI 输出；必须由 `.gitignore` 排除。
- 机密配置：`.env*`、密码、Token、私钥、钱包、Cookie 和完整连接串；只留在实际使用主机。
- 生产状态：数据库、systemd、Nginx、云资源和公开域名；任何写入或变更必须有明确授权。

## 数据库

- 默认只读。写入、DDL、导入、训练、评分、修复和模拟器启动均视为数据库写操作。
- `artifacts/v2-sim-data/` 是冻结基线，不得修改或重复导入。
- 写操作前必须确认目标数据库、影响范围、备份或恢复方案和验收查询；不得依赖模糊环境变量目标。
- 模拟器默认关闭，只有显式门禁和专用写库 URL 同时满足时才允许启动。

## 凭据与日志

- 凭据只通过环境或受控密钥机制读取，不进入代码、命令回显、响应、测试快照、文档或 Git 历史。
- 异常日志记录类型和安全上下文，不输出认证头、完整 URL 查询、连接串或业务明细。
- `.env.example` 只描述变量名和安全占位符，不复制真实环境值。

## 生产运行与外部平台

- 生产运行在运行主机上，与源码工作区同机（见 ADR-0006）；工作区不因"部署"而有内容白名单限制，
  但生产敏感操作（服务启停、Nginx、数据库写）一律需显式授权。
- 历史 Cloudflare Worker 不属于运行架构，不得部署。Cloudflare Workers AI 适配器仅用于只读文案生成，
  启用需要最小权限凭据、聚合数据白名单、调用限额、缓存和失败降级。
- 搜索引擎禁止索引是生产不变量：robots、HTML meta、Nginx 与 API 响应头不得被后续改动移除。

## 删除与恢复

- 删除前先用只读检查解析精确目标，避免宽泛路径、未解析变量和危险通配符。
- 重要数据先建立并校验恢复副本；完成后说明删除内容、恢复位置和是否仍可恢复。
- 不得清理其他项目、共享服务或未纳入任务范围的主机资源。
