## 入口与隔离

关联：[KI-076](../issues/KI-076-FRONTEND-PRESENTATION-CONTRACT.md)、
[KI-102](../issues/KI-102-六屏信息去重与全量可见布局重构.md)、

在 `frontend/` 执行：

```bash
pnpm exec playwright install chromium
pnpm run build:visual
pnpm run test:visual
```

`playwright.config.ts` 启动独立的 4187 端口预览，无 API 转发；测试只接受本地静态请求，全部 API 由固定夹具响应。
未知 API、写请求和外部域名请求均拒绝并使测试失败。不得改成生产 URL，不能使用真实数据库或 AI 请求替代夹具。
构建输出在 `frontend/output/visual-dist/`，失败证据与报告在同目录下的 `browser-results/`、`browser-report/`，均已忽略。
`/#/components` 是仅 visual 构建存在的组件展例，生产路由不包含该入口。

## 验收范围

- 固定时间、数据与浏览器，六屏和组件展例在 1920×1080、1366×768 下比较截图。
- 异步路由面板挂载完成后才快进虚拟时钟，避免代码分包速度把 Canvas 入场首帧误判为视觉回归。
- 同时验证面板边界、浏览器异常、降级来源、刷新失败、窗口变化、全屏常驻导航。
- 巡航点击必须打开具体事件的工单，抽屉须在缩放画布外且可按 Escape 关闭。
- 长指标、缺失值和零值由组件展例验证；焦点循环与恢复另有单元测试。

### 六屏信息架构专项

- A–F 六屏的主面板在设计画布内必须同时可见；页签、条件分支和抽屉不得替换整组主面板。
- 逐屏核对面板职责：同一事实只在一个专业面板完整展示，总览只保留摘要、状态和下钻入口。
- 六屏主画布的 Zone 必须各自从 1 连续编号且不重复；详情后缀不计入主面板序列。
- A1 五域、A2 指标及 D1 链路/结构指标应在各自分区内居中；A3 不得重新挤占省域摘要的主要面积。
- A2/A3 的长说明不得挤压标题与操作按钮，只常显短标题并通过整条标题栏悬停提示完整文字；A5 四项数字须中轴对齐，晚于当前快照的实时单据/凭证事件应触发数值缓动更新。
- A2 默认六项必须取全国汇总（建设完成率、纳入单位、已上线、上线率、双轨运行、尚未上线），点击地图省域后六项同步切换为该省；今日单据/凭证增量只在 A5 展示，A1/A2 不得重复该数字；A5 必须显示统计日期，单据与凭证必须属于同一业务日。
- A4 地图普通点击为单选，Ctrl/Command 点击可增删多选省份；A2 对多选范围的数量求和、建设完成率按纳入单位加权。点击“返回全国”后 A2 恢复全国口径，地图同步清除全部省份高亮。
- B2/C2 数字矩阵在两档视口下均须清晰可读，不得退回轴标签级小字号。
- D6 收窄为第三行左半区，但内部仍保持左侧规则区 5、右侧核验图 7 的比例；后端未提供离线稽核结果时
  显示“未核验”，不得显示 0 或空白冒充结论。D7 在右半区展示新数据审批/制证流转，历史存量不得混入。
- 台账使用有限行数、分页、抽屉或面板内局部滚动；标题、主 KPI 与主图不依赖滚动才能出现。
- 浏览器几何检查只能证明边界和可见性；信息密度、层级、居中观感与跨屏重复仍由人工审阅确认。

## 基准更新

基准存于 `frontend/e2e/screenshots/`。浏览器版本由锁文件固定，字体、操作系统和架构应与基准生成环境一致。
先检查差异原因，确认为预期设计变更后才运行 `pnpm run test:visual:update`；不得以自动更新基准掩盖回溢或错位。
截图比对证明渲染没有非预期变化，不代替人的审美判断。初始基准及重大视觉变更仍需用户审阅。
KI-102 的新布局在人工审阅完成前不得更新既有基线；代码已经部署也不等于视觉验收完成。

## 组件与规则扩展

优先在展例中加入失败输入，再修改所属组件；D 屏作为图表事实组合试点，不要求六屏同构。
新增行为先验证空数据、长文本、超大数字、窄容器及交互恢复，再迁入页面。
