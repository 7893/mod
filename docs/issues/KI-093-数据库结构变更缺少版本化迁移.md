# KI-093 · 数据库结构变更缺少版本化迁移

## 问题

仓库没有统一的 Schema 版本时间轴。Outbox 使用 [`deploy/projection-outbox.sql`](../../deploy/projection-outbox.sql)，AutoML 与日报表在 Python 中幂等建表，索引另由独立脚本维护。不同环境是否执行过某项 DDL 无法从一个版本号判断，也没有统一升级与回退入口。

## 完成定义

- [ ] 选定并接入单一迁移工具；
- [ ] 建立与现有生产结构相符的基线，避免重复创建或误改现有表；
- [ ] Outbox、AutoML、日报和索引等后续结构变化只从迁移时间轴进入；
- [ ] 发布前检查、升级失败处理和回退规则明确；
- [ ] 在隔离数据库完成从基线升级与回退演练。
