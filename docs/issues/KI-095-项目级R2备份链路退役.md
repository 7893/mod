## 事实校正（2026-09-17）

退役决定继续有效，但“数据库平台自带备份”不等于长期灾备或 PITR。OCI API 只读核验显示当前
MySQL.Free 实例的自动增量备份已启用、保留期 1 天、PITR 关闭。项目明确接受这一短恢复窗口，
不把 JPA/GitHub 的代码副本描述为数据库副本，也不再声称存在项目级第二套数据库备份。
