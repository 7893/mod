# KI-065 · 大屏图表 tooltip 越界遮挡、A4 时间轴未以当前为中心、C5 小环图圆心文字拥挤

- 状态：DONE
- 优先级：P2
- 更新日期：2026-09-09

- 关联：[已知问题看板](../KNOWN-ISSUES.md)、[前端架构与约束](../development/FRONTEND-ARCHITECTURE-AND-CONSTRAINTS.md)、`frontend/src/charts/theme.ts`

## 结论

三个界面细节缺陷，均为小幅调整、不涉及业务逻辑或数据口径变更：

1. **tooltip 越界遮挡（全屏通病，重点）**：全库 ECharts 图表的悬浮提示统一继承 `charts/theme.ts` 的
   `chartTooltip`，但该配置**未设置 `confine`，也无 `position` 回调**。当鼠标落在图表左缘（或上/右/下缘）时，
   tooltip 按默认方向弹出会**溢出本面板边界、被相邻面板遮挡**。C5（`RolloutView` 单位覆盖率环图）在最左侧
   悬浮时被左侧 C3 面板挡住是典型表现。需全屏统一治理，使 tooltip **恒定显示在本面板可视区域内**，
   并按鼠标位置自动翻转方向（左/右/上/下）。
2. **A4 时间轴未以当前日期为中心**：A4「上线与双轨走势」(`OverviewTrendChart`) 的横轴按 `snapshot.trend`
   顺序自左向右铺开，当前呈现为「今日(9/9)在最左刻度 → 10/1 在最右刻度」，只能看到未来、看不到过去。
   期望：**当前日期落在时间轴中间刻度**，左侧展示已过去的演进、右侧展示未来推进，形成以「今天」为中心的对称时间窗。
3. **C5 环图圆心文字拥挤**：C5 覆盖率环图半径很小（`radius: ['58%','78%']`），圆心叠加了
   `title.text`(百分比) + `subtext`(“单位覆盖率”汉字)，在小尺寸下显得拥挤。期望：**圆心不再显示中间文字
   （尤其汉字说明）**，改由悬浮 tooltip 呈现（tooltip 本身按第 1 项修复越界）。

## 只读证据（2026-09-09）

- `frontend/src/charts/theme.ts` 的 `chartTooltip` 仅含 `backgroundColor/borderColor/borderWidth/padding/textStyle`，
  **无 `confine`、无 `position`**。全库 `grep -rn "confine" frontend/src` 结果为 0 处，确认为统一根因。
- 全屏共 **28 处 tooltip 配置**，分布于 6 个图表配置文件与 3 个组件：
  `charts/{complianceOptions,rolloutOptions,panelOptions,operationsOptions,insightsOptions,constructionOptions}.ts`、
  `components/{OverviewTrendChart.vue, ChinaMap.vue, CockpitTopBar.vue}`。绝大多数通过 `...chartTooltip` 继承同一配置。
- A4：`components/OverviewTrendChart.vue` 的 `xAxis.data = props.data.map(v => v.date)`，数据源
  `DashboardView.vue` 的 `store.snapshot.trend`；轴仅按数组顺序平铺，无「当前日期居中」处理。
- C5：`charts/panelOptions.ts::createCoverageOption` 的 `title.text = "${rate}%"`、`subtext = "单位覆盖率"`
  居中叠于环心；`tooltip: { trigger: 'item', ...chartTooltip }`（无 confine / position）。

## 排查范围（要求全屏逐一核对，属本 KI 一部分）

对 A~F 屏上述 28 处 tooltip 全部核对越界风险，重点检查靠近面板边缘、位于窄栏或与相邻面板紧贴的图表：

- A 屏：A2/A3 构成图、A4 走势（`OverviewTrendChart`）、地图（`ChinaMap`，含 geo tooltip）。
- B 屏：任务阶段、培训、准备度等 `constructionOptions` 图表。
- C 屏：批次构成、**C5 覆盖率环图**、上线趋势矩阵（`rolloutOptions`）。
- D 屏：运营规模、凭证质量、集成结果、趋势（`operationsOptions`）。
- E 屏：合规率/批次监督（`complianceOptions`）。
- F 屏：风险维度、模型卡等（`insightsOptions`）。
- 顶栏 `CockpitTopBar.vue` 若含 tooltip 亦一并核对。

## 修复方向（待实施；最小改动、不牵扯其他变更）

1. **tooltip 越界（全屏统一收口）**：在 `charts/theme.ts` 的 `chartTooltip` 增加 `confine: true` 作为基线，
   使所有继承该配置的图表 tooltip 限制在图表 DOM 内、不溢出面板。对 `confine` 仍不足以避免遮挡的场景
   （如 pie/环图边缘、贴邻面板），补充 `position` 回调：依据 `point`（鼠标坐标）、`size`（tooltip 与容器尺寸）
   计算落点，越右则左展、越左则右展、越上则下展、越下则上展，保证始终落在本图表容器内。
   优先用统一基线覆盖大多数，仅对个别特殊图表单独加 `position`，避免逐处散改。
2. **A4 时间轴居中**：使横轴以「当前日期」为中间刻度。实现层面二选一（实施时定版，倾向前者以免改动数据契约）：
   - 前端轴锚点：保持数据不变，通过定位当前日期索引并对称取窗/滚动，使当前刻度居中显示；
   - 或数据窗口：由趋势数据窗口覆盖「今天前后各半」。任一方式都不得改变 A4 的数据口径与其它面板。
3. **C5 圆心文字**：移除 `createCoverageOption` 的 `title`（或至少移除 `subtext` 汉字，视觉上让环心留白），
   覆盖率读数改由已存在的 tooltip 呈现；tooltip 依第 1 项修复后不再越界。

## 明确边界（严格约束，防止范围蔓延）

- 本 KI **只**修上述三处（全屏 tooltip 越界规则 + A4 轴居中 + C5 圆心文字），不重做任何面板、不改配色/布局骨架、
  不动数据口径与后端接口、不改其它面板的既有交互。
- tooltip 修复以「统一基线 + 必要处 position 微调」为原则，不逐处重写各图表配置。
- 遵循前端三层契约（骨架/物料/Token），不引入 ad-hoc CSS 或任意值。
