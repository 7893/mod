# KI-033 · 前端UI优化美化（六屏协调优雅重构）

- 状态：IN-PROGRESS（2026-09-06 立项）
- 更新日期：2026-09-06
- 关联链接：[已知问题看板](../KNOWN-ISSUES.md)、[前端架构约束](../development/FRONTEND-ARCHITECTURE-AND-CONSTRAINTS.md)

## 目标
**好看、协调、优雅、大方**——以美观为唯一核心目标，技术问题是手段。
同时严守前端三层契约（骨架/CockpitPanel/Token），不造CSS屎山。

## 前端约束（与派单同步，执行方必须遵守）
- 所有面板必须用 `CockpitPanel` 包裹，严禁私有面板样式
- 颜色/间距/字号/圆角/阴影只用集中 Token（`theme.css` `@theme` + Tailwind 原子类），严禁散写任意值
- 零手写 `<style>` 块
- 单文件 ≤400 行，超出必须拆组件
- `make check`（含前端 arbitrary values lint）必须全绿

## 各屏问题清单

### A屏（项目总览）
1. A2-A3 强行合并（省域指标+批次推进）→ 拆成两个独立 Panel
2. A6-A8 强行合并（运营指标+联系人覆盖）→ 拆开，各自独立
3. A7 风险预警：最重要内容被压在最小格子里 → 扩大面积/调整比例
4. A4 趋势图太空旷 → 加小指标标注或调整比例
5. 三栏比例（390px+1fr+370px 固定像素）→ 考虑比例化，左右列弹性

### B屏（建设进度）
1. B1 tab切换（全景 vs 台账）视觉割裂 → 台账改为B5按钮下钻，B屏专注建设全景
2. B2 阶段分布 col-span-2 太空旷 → 调整密度或格子比例
3. B4 培训详细表格不符合大屏气质 → 换成图表/可视化卡片
4. B5 期初数据准备度 → 保留（已有交互，设计合理）

### C屏（上线推广）
1. C2 八批次卡片缩放后挤 → 优化最小宽度和缩放适应
2. 中部三栏 min-h/max-h 固定像素 → 改为弹性比例高度

### D屏（风险预警）
1. D2(困难户清单)与D4(AI模型)面积相等但内容悬殊 → 调整2×2比例
2. D4 AI模型块内容空洞 → 缩小格子或充实内容
3. D5 AI解说空态（loading/空白）设计差 → 优雅的空态

### E屏（合规监督）
1. E4批次合规只显4列（8批次截断）→ 展示全部8批
2. E2/E3 固定像素高度 → 改弹性

### F屏（业务运营）
1. zone 命名残留（D1/D2标注）→ 改为F1/F2
2. D5接口集成块内容稀少面积大 → 充实或缩小
3. D7数据质量 col-span-2 内容太少 → 调整
4. D2流水线数字太小 → 提升可读性
