# KI-054 · 文档生命周期约束与历史内容保全闸门

- 状态：DONE（2026-09-08）
- 优先级：P1
- 更新日期：2026-09-08
- 适用范围：全仓库文档的分类、索引、状态迁移、当前事实更新、历史保全与提交闸门
- 关联：[KI-019 文档组织治理](KI-019-文档组织治理.md)、[KI-025 文档与代码同步半机制](KI-025-文档与代码同步半机制.md)、[KI-030 协作机制与文档治理演进](KI-030-协作机制与文档治理演进.md)

## 问题

项目已建立 `CURRENT-STATE`、`INDEX`、`KNOWN-ISSUES`、ADR 与历史归档的分层框架，但只有链接检查是真正的阻断闸门。只读审计确认以下腐化已经发生：

1. `CURRENT-STATE.md` 同时堆积当前事实与历史实施过程，测试数量等动态口径已过期。
2. `KNOWN-ISSUES.md` 与 KI 详情的状态可独立修改，已出现 `OPEN`/`DONE` 相互冲突，并混用 `RESOLVED`、`COMPLETED`、`DRAFT` 等未统一口径。
3. `INDEX.md` 和分目录 README 没有覆盖新增现行文档；大量路径用代码文本而非 Markdown 链接，死链检查无法触达。
4. `check_doc_sync.py` 自称闸门但始终返回成功，且未覆盖前端与拟真引擎，无法阻止事实漂移。
5. 现行规范没有把“历史内容永不删除”落成机器可检查的保全协议。

## 根因

- 文档组织依赖人和 AI 自觉，缺少状态、元数据、索引覆盖和删除保护的自动校验。
- 没有定义“当前事实被取代”的原子迁移流程，导致旧事实要么被直接改写，要么永久堆在当前入口。
- 冻结历史、当前切片和可修改规范的修改边界没有统一到同一套操作规则。

## 治理决策

1. **内容永不删除**：任何已跟踪文档都不得物理删除。历史、证据和 ADR 正文只允许追加状态标记、取代关系或勘误，不得删减、覆盖或美化当时记录。
2. **过时只标记或迁移**：部分过时时标明精确范围和取代来源；整体过时时用 Git 重命名完整移入 `docs/history/`，不改写原文。
3. **当前切片保持纯净**：`CURRENT-STATE.md` 只保留核验后的当前事实。撤下旧事实前，先将被取代的完整内容收入带日期历史切片，再在同一提交更新当前入口。
4. **一次状态迁移是一个事务**：KI 状态变化必须同时更新看板与详情，只允许 `DRAFT`、`OPEN`、`IN-PROGRESS`、`DONE`。
5. **可发现才算存在**：所有现行规范、运维手册和目录入口必须使用真正 Markdown 链接纳入 `INDEX.md`。

## 实施范围

- 完善 `AGENTS.md`、`ENFORCEMENT.md`、文档格式与生命周期规范。
- 修正现有 KI 状态冲突和索引漏项，不删除任何历史内容。
- 新增文档治理检查器，阻断文档删除、冻结正文减损、KI 状态分裂、必需元数据缺失和现行索引漏项。
- 将事实同步检查改为阻断式，覆盖后端、前端、拟真引擎、数据库 Schema 和部署配置。
- 为上述检查补充自动化回归测试，并纳入 `make check` 与 CI。

## 验收标准

- [x] 已跟踪文档的物理删除会阻断检查，Git 重命名迁移不被误判。
- [x] `docs/history/`、`docs/evidence/`、`docs/decisions/` 与 `archive/` 中的冻结正文被删减时会阻断，追加勘误或状态标记允许通过。
- [x] KI 看板和详情状态不一致、重号或使用非法状态时会阻断。
- [x] 新增或修改的现行文档缺少标题、更新日期、状态或适用范围时会阻断。
- [x] 现行规范、运维和 Runbook 未被 `INDEX.md` 以 Markdown 链接收录时会阻断。
- [x] 核心代码与部署事实变更未同步 `CURRENT-STATE.md` 时检查失败。
- [x] 局部测试、文档链接检查与全量 `make check` 通过。

## 实施结果

- 将“文档不删除、冻结正文只增不减、当前事实先归档再替换”同步写入仓库硬约束、强制执行规范、文档格式规范和生命周期规范。
- 新增 `scripts/project/check_document_governance.py`，对全仓库 Markdown 文档和 `docs/`/`archive/` 文本记录实施删除保护，并对冻结目录实施正文减损保护。
- 统一 KI 状态词汇，修正 KI-028、034、035、045、046、051 已有状态分裂；KI-028 追加后续闭环记录，原始问题内容全部保留。
- 修复顶层索引与开发导航漏项，把路径替换为可被死链工具检查的 Markdown 链接，并纳入 HeatWave、Cloudflare Browser Rendering、双轨定义和灾难恢复手册。
- 将 `check_doc_sync.py` 从软警告升级为阻断检查，扩展至前端、拟真引擎和数据库领域；两项治理工具及 8 项回归测试已纳入 `make check` 与 CI。
