# KI-028 · 真实评估暴露模型指标不可信（数据过度可分 / 回归无效）

- 状态：OPEN
- 更新日期：2026-09-05
- 关联链接：[已知问题看板](../KNOWN-ISSUES.md)、[KI-015](KI-015-风险模型训练集自评分准确率不可信.md)、[KI-023](KI-023-AutoML质量分硬编码兜底.md)

## 背景
KI-015 已用 train/test split 做了真实评估（消除自评分假象，任务本身验收通过）。真实测试集指标反而暴露两个模型质量问题：
- **风险分类模型**：独立测试集 accuracy 仍 = 1.0（train/test 均 100%）。这不是自评分假象（切分正确），而是**模拟数据的风险标签过度可分**——`risk_flag` 几乎是特征的确定性函数，模型"完美"但不真实（现实风险不会 100% 可预测）。对外展示 100% 反而"一眼假"。
- **单据量回归模型**：测试集 R² = -0.0135（负），即预测能力约等于零（不如用均值）。当前特征不足以预测日增单据。

## 已处置（止血）
- 展示层增加"有效性阈值"判定（`backend/app/api.py`、前端 `InsightsView.vue`，commit 2ab5609）：
  回归 R²>0、分类 accuracy∈(0.5,1.0) 才判"已就绪"；否则显示"已训练，验证未达标"（`VALIDATION_FAILED`），
  不把负 R² 或退化的 1.0 当可信预测对外展示。线上已如实呈现。

## 待处理（根因，需另行设计）
- **风险标签过度可分**：根因在模拟器生成 `risk_flag` 与特征时过于规整，缺现实噪声/灰色地带。
  要让准确率自然落到可信区间（约 80~90%），需在拟真引擎生成风险相关数据时引入**受控噪声与模糊边界**
  （部分单位特征相近但结局不同），使风险不再 100% 可预测。属拟真引擎数据生成层改动。
- **回归模型无预测力**：需审查/扩充 `ml_feat_doc_delta` 特征（如正确的周期性特征：星期、是否月末、
  节假日、历史同期），或重新界定该模型是否值得保留。
- 二者均与"局中人下钻可信度"相关：矛（真实风险）与盾（预测）要读同一有噪声的真实事实源。
- 依赖：与拟真引擎（KI-026 系列）咬合；改动须经主控设计 + 授权后由 agy 执行。
