## 目标
将 `backend/app/simulation/` 平移到顶层 `simulation/`，使拟真引擎在代码结构上
也体现其独立地位（运行层面已是独立 systemd 服务）。

3. 建 `simulation/__init__.py`（如需）、`simulation/tests/`（迁移测试）
4. 全局替换 import 路径：`from app.simulation.` → `from simulation.`
5. 调整 `scripts/agy/run_simulator_service.py` 的 sys.path
