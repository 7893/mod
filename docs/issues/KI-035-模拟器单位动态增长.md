# KI-035 · 模拟器单位动态增长（第八批蓄水池入池）

- 状态：OPEN（2026-09-06 立项）
- 优先级：P2
- 更新日期：2026-09-06
- 关联：[拟真引擎业务规范](../development/SIMULATION-PIPELINE-SPEC.md)、[数据与安全标准](../development/DATA-AND-SECURITY-STANDARD.md)、[ADR-0009 拟真引擎平移](../decisions/0009-拟真引擎平移为顶层独立模块.md)

## 背景

当前模拟器只推进**存量 2000 家单位**的状态，`org_unit` 表只做 `UPDATE status`，从不 `INSERT` 新单位——单位总数恒定 2000。
但 [SIMULATION-PIPELINE-SPEC](../development/SIMULATION-PIPELINE-SPEC.md) 第 16 行已定义**第八批为"全网未启动动态储备池"**，
第 84-86 行甚至预留了"储备池单位入池事件"的 SSE 样例（`【广东】新设全资子公司已登记入库，自动纳入第八批储备池`）。
即：框架早已为单位增长预留接口，但**尚未实现真正的入池（org_unit 插入 + 连锁数据生成）**。

真实项目中，集团新设/新划转/新并购企业会陆续纳管，单位总数会缓慢增长。补上这一能力可让模拟更逼真。

## 目标

实现**低频、真实、自洽**的单位动态增长：新单位偶发入池第八批（未启动），连带生成人员/任务/准备度，
交由现有生命周期推进器接管，全程遵守既有模拟器约束，不产生任何脏数据。

## 核心设计

### 1. 频率与幅度
- **每周新增 1~3 家**（偶发，不是每天冒一堆）。符合"随时吸纳新设/新排查单位"的真实低频语义。
- 由常驻模拟器服务按节律触发；单位总数从 2000 缓慢增长（2000→2001→…）。

### 2. 入池规则（严守 SIMULATION-PIPELINE-SPEC）
- 新单位**一律入第八批**，状态 `未启动`，`constructionPct = 0.0`。
- **零业务数据**：第八批单位严禁产生单据/凭证/集成/双轨（规范约束矩阵第 62-63 行）。
- 后续由生命周期推进器（`lifecycle_advancer`）在满足门禁后逐步推进，不得凭空出现在已上线批次。
- SSE 入池事件按规范样例广播（`【省份】新设…自动纳入第八批储备池`）。

### 3. 名字生成（最易造脏，必须复现既有构词法）
现有 2000 家单位名/人名是一次性冻结在库的，模拟器**没有名字生成器**，需新建：
- **单位名构词法**：古雅地名（羊城/象山/青州/金陵/奉天/濂溪…）+ 行业（林业/能源/生物科技/金融/制造…）+ 组织后缀（研究院/事业部/有限公司/工坊/设计院…）。新名字必须符合此构词法。
- **查重**：新单位名不得与已有 2000 家重名。
- **人员名**：中文姓名，符合现有 `org_user` 风格；新单位配若干经办人/项目联系人。
- **省份/产业归属**：新单位要有合理的省份（34 省之一）和产业板块归属。

### 4. 连锁数据（一个单位一整套，原子生成）
入池一个新单位，同一事务原子写入：
- `org_unit`（1 行，第八批，未启动，省份/产业归属）
- `org_user`（若干人员名录，否则后续单据无经办人可挂）
- `construction_task`（建设任务，进度 0 或极低）
- `data_readiness`（数据准备度，0）
- 遵守写库器约束：只增不删、零 schema 变更、审计留痕、`MOD_SIMULATION_ENGINE_ENABLED` + `execute` 双门禁。

### 5. 勾稽与展示同步（牵一发动全身，核心难点）
"总纳管 2000 家"当前被多处写死，单位增长后必须同步：
- **overview 勾稽**：`orgTotal` 变动态，第八批储备数跟着涨；所有以 `orgTotal` 为分母的百分比（上线率等）分母随之更新。
- **SIMULATION-PIPELINE-SPEC 第 96 行**"总纳管 2,000 家"的勾稽表述改为"含动态增长"口径。
- **前端展示**：任何硬编码 2000 的地方改为读实时值。
- **AutoML 特征**：确认特征表按实际单位数生成，不假设固定 2000。
- **fallback 快照**：`v2-sim-snapshot.json` 的 orgTotal 与增长口径一致（或标注为演示基线）。

### 6. 时间线与真实性约束
- 入池日期接续当前，只向前，不倒流（同存量治理约束）。
- 增长曲线平缓（每周 1~3），不得暴增。
