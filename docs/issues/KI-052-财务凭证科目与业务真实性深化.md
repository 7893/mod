## 背景

KI-051 完成数据规模扩充（凭证达 500 万级）后，对现有数据分布做真实性核查，发现 `ExpensePlaybook`
既有生成逻辑存在若干"一眼假"的财务失真点（非 KI-051 引入，是既有设计的单薄，放大后更明显）：

1. **凭证科目严重单一**：所有凭证分录固定为"借 1002 银行存款 / 贷 2202 应付账款"一种组合
   （各 500 万条完全相同）。真实财务凭证科目丰富，费用报销应涉及管理费用、差旅费、办公费、
   业务招待费、应交税费（进项/销项）、库存现金、其他应收款、职工薪酬等多科目借贷。
2. **单据金额区间失真**：费用报销单金额最大到约 319 万元，明显偏离真实费用报销量级
   （报销通常几百到几万，大额应走采购/合同而非报销单）。
3. **单据∶凭证 ≈ 1.17∶1**：接近机械一对一。真实中存在月末多单合并制单、一单多凭证冲销等，
   比例应更灵活。
4. **业务类型单一**：目前只有"费用报销单"一种业务。真实单位有采购付款、差旅报销、
   工资发放、税费缴纳、往来结算等多种业务，各自科目与金额特征不同。

## 目标

深化费用报销及相关业务链的会计真实性：**凭证科目体系多样化、金额分布贴合真实业务量级、
单据-凭证关系灵活、业务类型丰富**，使数据在财务专业视角下经得起推敲，同时严守全链勾稽。

## 核心设计方向（待细化）

1. **会计科目体系**：
   - 建立符合《企业会计准则》的常用科目库（管理费用/差旅费/办公费/业务招待费/应交税费/
     库存现金/银行存款/其他应收款/应付职工薪酬/预付账款等）。
   - 按业务类型选择合理的借贷科目组合，多行分录（不止两行），借贷仍严格平衡。
2. **金额合理性**：
   - 费用报销：数百至数万元为主，极少数上限；大额业务归入采购/合同类而非报销。
   - 金额与科目匹配（如差旅费金额区间、招待费限额特征）。
3. **单据-凭证关系**：
   - 支持一对一、月末多单合并制单、一单多凭证（含冲销）等真实模式。
4. **业务类型扩展**（可分期）：
   - 除费用报销外，逐步引入采购付款、工资发放、税费缴纳、往来结算等，各具科目/金额/周期特征。
5. **与既有数据的衔接**：
   - 新逻辑用于 mod-simulator 后续生成；存量 500 万历史凭证是否回填改造需评估（回填代价大，
     可接受"新数据更真实、历史保留"，或专门批处理改造历史科目分布）。

## 约束
- 全链勾稽 100% 平衡（多行分录借贷相等、金额与明细一致、无孤链）。
- 复用拟真引擎既有安全机制（门禁、审计、只增不删、时间只向前）。
- 科目/金额/业务均离线规则驱动，零运行时 AI；中文科目名符合会计惯例。
- 回归测试覆盖：多科目借贷平衡、金额区间、单据-凭证关系、各业务类型。

## 完成定义
- 凭证科目多样（非单一银行存款/应付账款），借贷多行且平衡。
- 金额分布贴合真实业务量级；业务类型不再单一。
- 单据-凭证关系体现真实模式；全链勾稽 0 缺陷。
- `make check` 全绿；文档同步；存量历史处理策略明确记录。
