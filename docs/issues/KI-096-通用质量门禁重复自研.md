# KI-096 · 通用质量门禁重复自研

- 状态：DONE
- 优先级：P3
- 更新日期：2026-09-21
- 适用范围：Git hooks、凭据扫描、文档链接、提交信息、前端静态检查
- 来源：[KI-088](KI-088-通用基础能力重复自研与工具链收敛缺口.md)

## 问题

仓库以多个项目脚本分别实现凭据扫描、Markdown 链接检查、提交信息校验和部分通用 hook 编排，并在本地 hooks、Makefile 与 GitHub Actions 中重复接线。业务专有契约检查应保留，但通用规则的实现、测试和升级成本不应长期全部由项目承担。

## 处置结果

| 能力 | 迁移前 | 当前权威入口 | 处置 |
|---|---|---|---|
| Git hook 编排 | `.githooks/` 长 shell 流程 | `.pre-commit-config.yaml` + 极薄追踪 hook | 替换通用文件选择/隔离，`make check` 仍为完整验收 |
| 凭据扫描 | `scan_secrets.py` 162 行 | `detect-secrets` 1.5.0 | 删除自研实现，本地与 CI 共用 pre-commit hook |
| 提交信息 | `validate_commit_message.py` 104 行 | `gitlint` 0.19.1 + `.gitlint` | 删除自研实现，保留英文小写、Conventional Commit 和 7 词上限 |
| Markdown 链接 | `check_doc_links.py` 114 行 | Lychee 0.24.2 | 删除自研实现，以 offline 模式检查本地链接 |
| 前端 TS/Vue | 无通用 lint | ESLint + typescript-eslint + eslint-plugin-vue | 新增生态标准错误规则 |
| 前端 CSS/Vue style | 仅 MOD 正则脚本 | Stylelint + MOD 专有契约 | 通用语法交给 Stylelint，Token/文件集/字号位置继续保留 |

工具能力、取舍、锁定和许可核验见 [ADR-0018](../decisions/0018-通用质量门禁优先采用成熟工具.md)。
被取代的 3 个脚本与 `backend/tests/test_repository_gates.py` 同步删除，共减少 429 行手写实现/测试；
CI 同时删除已由 `make check` 覆盖的重复前端与文档步骤。

## 保留的项目契约

`check_history_integrity.py`、`check_semantic_contracts.py`、`check_document_governance.py`、
`check_doc_sync.py`、`check_changelog.py`、`sanitize_history.py`、`lint_frontend_styles.py` 与
`lint_frontend_arbitrary_values.py` 表达 MOD 特有的历史、文档、业务和大屏契约，不作为通用工具的重复实现删除。
