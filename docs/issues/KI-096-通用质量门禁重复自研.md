# KI-096 · 通用质量门禁重复自研

- 状态：OPEN
- 优先级：P3
- 更新日期：2026-09-16
- 适用范围：Git hooks、凭据扫描、文档链接、提交信息、前端静态检查
- 来源：[KI-088](KI-088-通用基础能力重复自研与工具链收敛缺口.md)

## 问题

仓库以多个项目脚本分别实现凭据扫描、Markdown 链接检查、提交信息校验和部分通用 hook 编排，并在本地 hooks、Makefile 与 GitHub Actions 中重复接线。业务专有契约检查应保留，但通用规则的实现、测试和升级成本不应长期全部由项目承担。

## 完成定义

- [ ] 按“业务专有 / 通用能力”列出脚本、调用方和测试；
- [ ] 对通用能力评估成熟工具的覆盖、安全性、维护状态和许可证；
- [ ] 每次引入工具时同步删除或显著缩减对应脚本与测试；
- [ ] 本地与 CI 使用同一配置，失败语义一致；
- [ ] 没有形成新旧双轨长期共存。

## 操作边界

本条目不授权安装工具、修改开发机全局配置或改变 CI 权限。若成熟工具不能减少仓库代码和维护面，应保留现有实现并记录理由。
