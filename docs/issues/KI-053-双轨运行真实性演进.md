## 背景

已在 [双轨运行与脱离双轨定义](../development/DUAL-RUN-DEFINITION.md) 中明确"双轨"与"脱离双轨"的
业务定义与硬性门槛，并核实项目已实现且运行（双轨运行中约 326 家、已脱离双轨约 1192 家、
双轨核对约 3.17 万笔、一致率约 92.7%，"只进不退" + 跃迁留痕 + 期初差异 +7 天因果）。

系统是活的、持续演进。当前双轨模型仍有可深化的真实性空间，登记本 KI 跟踪，不强行一次做完。

## 演进方向（候选，实施时再细化并分期）

1. **双轨受阻 / 延期建模**：
   - 现状：状态机"只进不退"，双轨期只要达标就前进。
   - 真实中：双轨期若发现重大不一致或阻断性差异，会**延长双轨期、甚至暂停上线整改**。
   - 方向：引入"双轨受阻→延期"的显式状态或计时惩罚（不违反"不倒退到前一阶段"的前提下，
     体现"卡在双轨更久"），使少数单位出现真实的双轨拉锯。

2. **脱离门槛分批 / 分行业差异化**：
   - 现状：脱离双轨门槛全局统一（14 天、一致率 98% 等）。
   - 方向：不同批次、不同规模/行业单位的脱离标准差异化（如大型单位核对笔数要求更高、
     欠发达地区节奏更慢），更贴合真实推广的非均质性。

3. **双轨一致率的周期性波动**：
   - 方向：结合财务周期（月末结账、季度末、报税期），双轨核对强度与差异呈现真实节律
     ——月末核对量大、差异暴露多，平时平稳。与 KI-052 的作息/周期节律呼应。

4. **差异原因的真实语料**：
   - 方向：不一致核对附带真实的差异原因（尾差、时间性差异、科目映射差异、跨期挂账等），
     与现有 business_corpus 的卡点事由体系打通，让双轨差异"有故事"。

## 约束
- 严守既有铁律：只进不退（不倒退到前序阶段）、跃迁留痕、第六批以外不产生双轨记录、全链勾稽。
- 复用拟真引擎既有安全机制（门禁、审计、只增不删、时间只向前）。
- 任何门槛/口径改动同步更新 `DUAL-RUN-DEFINITION.md` 与 `CURRENT-STATE.md`。
- 回归测试覆盖新增的双轨行为（延期、差异化门槛、周期波动）。
