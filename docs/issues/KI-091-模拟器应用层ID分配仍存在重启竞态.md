# KI-091 · 模拟器应用层 ID 分配仍存在重启竞态

- 状态：DONE
- 优先级：P1
- 更新日期：2026-09-21
- 适用范围：模拟器主键生成、重启恢复、并发事务
- 来源：[KI-085 第 6 项](KI-085-核心架构缺陷与数据安全治理.md)、[KI-083](KI-083-模拟器重启ID分配器竞态导致短暂熔断.md)

## 问题

[`simulation/engine_context.py`](../../simulation/engine_context.py) 仍通过 `SELECT MAX(id)` 加固定 `DEFAULT_ID_RESTART_BUFFER = 100` 初始化进程内 `IdAllocator`。该缓冲降低了既有重启竞态的发生概率，却没有让数据库成为主键分配权威；在途事务超过缓冲或出现并行实例时仍可能冲突。

## 完成定义

- [ ] 主键分配不再依赖固定数值缓冲猜测；
- [ ] 单据、明细、凭证及关联记录能够取得数据库权威 ID 并保持事务原子性；
- [ ] 覆盖重启、在途事务和误启动第二实例的并发测试；
- [ ] 不削弱现有配额、熔断、业务勾稽和 Outbox 原子性；
- [ ] 生产切换与回退另行授权并留存验收结果。
