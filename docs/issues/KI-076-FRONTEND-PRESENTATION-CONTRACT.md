# KI-076 · 前端展示事实、组合布局与视觉回归缺口

更新日期：2026-09-12
- 状态：DONE
适用范围：六屏展示、治理巡航、公共面板、抽屉、前端验证与对应现行规范

## 问题与证据

- 巡航组件内置三条固定剧情，E 屏未消费查看事件，不能随治理事实更新。
- 顶栏以请求错误代替数据来源判断，成功收到 fallback 时仍可能显示在线。
- D4/D5/D6 重复定义图表与事实栏布局；关键指标可能被省略而无完整值入口。
- 抽屉位于整体缩放画布内部，缺少统一的窗口挂载、焦点管理与键盘关闭行为。
- 常规测试未验证实际浏览器排版；现有截图脚本不冻结数据与时钟，也没有基准比较。
- 前端规范的路由、布局比例及测试规范中的旧模块、接口描述与源码不一致。

## 修复范围与验收

- [x] 巡航与广播使用同一治理事件源，空数据不编故事，查看定位具体工单。
- [x] 顶栏区分实时、降级、刷新受阻，并提供数据时点。
- [x] D 屏复用有限变体的图表事实组合；完整数字和长标题可查看。
- [x] 抽屉统一挂载到窗口，Escape、焦点循环和关闭后焦点恢复可验证。
- [x] 增加离线固定场景、六屏截图比较与交互验收，禁止测试访问生产 API。
- [x] 更新现行规范、索引与当前状态，运行相关测试和完整质量门禁。

## 边界

用户已授权本地修复和文档登记；不写数据库、不调用外部 AI、不发布生产。
保留任务开始前 KI-070/KI-071 及看板的用户修改。测试输出保存在忽略目录。
组件展例与视觉回归是验证上述缺陷的配套工具，不扩展为独立产品。
