## 恢复规则

- 本机受限原件的异机加密备份和恢复演练尚未执行，不得把清单或哈希描述成备份完成。
- 恢复后运行 `python3 scripts/project/check_history_integrity.py`，所有文件哈希一致才算原件恢复成功。
- 需要协作阅读的受限资料应新建可追溯稳定 ID 的脱敏副本；原件继续保留，二者不得互相覆盖。
- 新增历史件时分配下一个稳定 ID，同步本目录、完整性清单和 `docs/INDEX.md`。
