二、你需要手工完成的事情

建议在 MBP 上操作，不需要安装任何软件，只用系统自带 SSH 和浏览器。

（一）进入 USA DataEase

1. 在 MBP 终端建立隧道：

   ssh -N -L 127.0.0.1:8180:127.0.0.1:8180 usa

2. 保持该终端窗口不关闭，在浏览器打开：

   http://127.0.0.1:8180

3. 使用 DataEase 管理员账号登录。
   - 用户名：admin
   - 当前密码保存在 JPA：/home/ubuntu/mod/archive/component-labs/dataease-lab/automation/login.mjs
   - 不要在聊天、截图或文档中复制密码。

（二）把 DataEase 数据源改为美国 mod_s

1. 进入“数据源”页面。
2. 找到现有数据源“MOD BI Lab”。
3. 点击其编辑入口，不要删除数据源，也不要新建同名数据源。
4. 在另一个终端查看只读账号连接参数：

   ssh usa "grep -E '^MOD_(DB_HOST|DB_PORT|DB_NAME|BI_DB_USER|BI_DB_PASSWORD)=' /home/ubuntu/mod/.env"

5. 按下面对应关系填写：
   - 主机名/IP：MOD_DB_HOST
   - 端口：MOD_DB_PORT
   - 数据库名称：MOD_DB_NAME（应为 mod_s）
   - 用户名：MOD_BI_DB_USER（应为 mod_bi_reader）
   - 密码：MOD_BI_DB_PASSWORD
   - 额外 JDBC 参数：allowPublicKeyRetrieval=true&useSSL=false
6. 点击“校验”。只有显示连接成功后才点击“保存”。
7. 不修改数据集字段、不删除数据集、不改变仪表板布局。

（三）检查 DataEase 已迁移内容

1. 数据集页面应看到以下 5 个数据集：
   - MOD-单位建设推广
   - MOD-每日上线趋势
   - MOD-问题风险
   - MOD-业务运营
   - MOD-科目分析
2. 打开“MOD驾驶舱”目录中的“MOD建设推广运营驾驶舱”。
3. 点击刷新或“更新图表数据”。
4. 应看到 7 个组件正常出数，不能出现数据源失效、字段缺失或 SQL 错误。
5. 暂时不要调整视觉效果和业务口径；先确认全链路正常。

（四）进入 USA NocoDB

1. 另开一个 MBP 终端建立隧道：

   ssh -N -L 127.0.0.1:8181:127.0.0.1:8181 usa

2. 保持终端窗口不关闭，在浏览器打开：

   http://127.0.0.1:8181

3. 若出现首次初始化页面，创建你自己掌握的管理员账号和强密码。
4. 管理员密码由你保存，不要写入项目仓库或聊天记录。

（五）让 NocoDB 连接美国 mod_s

1. 选择“Connect External Data”或“连接外部数据源”。
2. 数据库类型选择 MySQL。
3. 在另一个终端查看编辑账号参数：

   ssh usa "grep -E '^MOD_(DB_HOST|DB_PORT|DB_NAME|TABLE_DB_USER|TABLE_DB_PASSWORD)=' /home/ubuntu/mod/.env"

4. 按下面对应关系填写：
   - Host：MOD_DB_HOST
   - Port：MOD_DB_PORT
   - Database：MOD_DB_NAME（应为 mod_s）
   - Username：MOD_TABLE_DB_USER（应为 mod_table_editor）
   - Password：MOD_TABLE_DB_PASSWORD
5. 测试连接成功后保存。
6. 该账号允许维护的 6 张过程管理表为：
   - rollout_unit_status
   - construction_task
   - data_readiness
   - opening_data_result
   - project_issue
   - project_risk
7. 不要尝试删除表、改表结构或连接 modo_db。
