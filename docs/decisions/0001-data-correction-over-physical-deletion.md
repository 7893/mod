# ADR-0001: 数据订正优先用查询过滤，而非物理删除

- 状态：采纳
- 日期：2026-09-04

## 背景
2026-09-03 曾有脚本为让“未上线单位无业务”符合模拟因果，物理删除约 1500 万行生产（演习库）
数据，无备份、无留痕，且事后未更新事实文档。此为不可逆损失（见 [KI-005](../issues/KI-005-unlaunched-org-history-deletion.md)）。

## 决策
当展示层/模拟层需要“某类数据不出现”时，优先在查询层用过滤（WHERE 条件）实现，
而非物理删除底层数据。物理删除仅在有充分理由、显式授权、备份与留痕齐备时才可进行。

## 理由
- 删除不可逆；过滤可逆、可调整、不损失数据。
- 模拟器/展示层的假设不应反向驱动对底层数据的破坏（因果倒置）。
- 演习库虽无真实数据，但精心生成的模拟数据同样是需保护的资产。

## 后果
- 引擎与查询层以过滤表达“可见性”，不以删除表达。
- 任何删除均受 `ENFORCEMENT.md` 闸门 B 约束：授权 + 只读核查 + 备份 + dry-run + 留痕。
