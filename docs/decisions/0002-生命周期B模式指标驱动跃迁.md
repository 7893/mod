# ADR-0002: 生命周期推进采用 B 模式（达标才跃迁）

- 状态：采纳
- 日期：2026-09-04

## 背景
拟真引擎需模拟单位阶段演进（收集→建设→双轨→上线）。两种方式：
A 预排时间表到期跃迁；B 依真实业务指标达标才跃迁。

## 决策
采用 B——单位阶段跃迁由真实指标决定（如双轨一致率、持续天数、无阻断高风险）。

## 理由
- B 更真实：表现差的单位自然延期，形成真实快慢分布，符合“局中人不知道”标准。
- 与矛盾咬合：困难户由业务流自然产生，决策支撑（盾）能从同一指标真实预测到，天然自洽。
- A 更简单但会产生“到点就跃迁”的不合理感；B 复杂但真实，取其真实。

## 后果
- 需“快电影喂慢电影”：业务流须让指标朝终将达标演进，否则单位永不毕业。
- 三条防坑纪律：只进不退、持续达标 N 天才跃迁、跃迁有过程（申请→评审→变更→留痕）。
