# ADR-0004: 停用与废弃内容一律归档，不删除

- 状态：采纳
- 日期：2026-09-04

## 背景
项目中不断产生停用/废弃的资产：历史脚本、停用的协作状态机、历史过程文档等。
需要一致的处置方式，避免误删可追溯资产，也避免它们冒充现行内容。

## 决策
停用/废弃内容**移入 `archive/`（回收站）或 `docs/history/`**，保留内容不改，
不物理删除。仅从活跃代码路径与扫描范围中移出。

## 理由
- 归档保留可追溯性；删除不可逆。
- 项目本身为实验/演示性质，历史资产有参考与考证价值。
- 与 ADR-0001（订正优先非删除）一脉相承：默认可逆、慎用不可逆。

## 后果
- 含明文凭据的废弃脚本已归档 `archive/legacy-db-scripts/`；协作状态机归档
  `archive/legacy-collaboration/`；历史编号文档归档 `docs/history/`。
- 归档区排除出 pre-commit 凭据扫描（回收站不作活跃代码扫描）。
- 彻底删除（如 Git 历史清理）属高风险，需另行显式授权。
