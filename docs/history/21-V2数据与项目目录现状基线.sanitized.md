- `modo_db`：其他项目数据库，不属于 MOD，禁止修改。

## 五、整理原则

1. `/home/ubuntu/mod` 是唯一项目主目录。
2. 历史资料归档但不删除。
3. V1 工具移入 `legacy-v1`，现行 V1 运行代码暂时保留。
4. V2 封版数据集中进入 `artifacts`，所有代码和文档统一使用项目内路径。
5. 原始项目材料进入 `references`。
6. 任务书、运维清单和验收证据分别进入 `docs/tasks`、`docs/operations` 和 `docs/evidence`。
7. 敏感配置不因整理而复制或集中。
