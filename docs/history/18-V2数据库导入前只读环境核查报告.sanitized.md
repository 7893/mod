## 五、 风险分析与防范预案

1. **共享实例性能竞争风险**：
   - **风险描述**：`MySQL.Free` 为单计算节点，大批量全量写入若突发并发过高，可能导致 Buffer Pool 命中率下降，引发 `mod_s` 演示大屏 API 瞬时响应延迟。
   - **防范措施**：导入程序采用单线程分批流式写入（单批次 5,000 行），每批提交后休眠 50ms，导入前中后实时监控 `Threads_connected` 与查询时延，一旦发现连接数激增即刻熔断。
2. **时区与格式转换风险**：
   - **风险描述**：MySQL 实例时区为 `UTC`，若未显式指定会话时区，可能导致国内业务日期或时间戳偏移 8 小时。
   - **防范措施**：在数据库连接建立的第一条 SQL 显式执行 `SET time_zone = '+08:00';`，所有空日期字符串必须转换为 `NULL`。
