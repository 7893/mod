# MOD 当前部署与运维基线

> 状态：历史基线，内容早于当前 V2 根路径部署。禁止按本文执行；当前事实见 `CURRENT-STATE.md`。

版本：1.0  
原状态：现行（2026-08-30）

## 一、当前定位

当前系统是可长期访问的 S 模式正式演示环境，用虚构数据展示新一代数智财务运营管控平台的建设、推广、双轨运行和运营分析全过程。

它不是生产业务系统。进入人工填报 M 模式或生产接口 P 模式前，必须重新确认认证、授权、审计、数据来源和安全边界。

## 二、现行架构

```text
浏览器
  │ HTTPS
  ▼
USA Nginx：/mod/
  ├─ Vue 3 静态页面
  └─ /mod/api/ → FastAPI 127.0.0.1:8100
                         │ OCI 私网
                         ▼
                  MySQL HeatWave / mod_s
```

- 演示入口：`https://<production-domain>/mod/`
- USA 公网 IPv4 和 IPv6 的 HTTP 根地址均可访问，并自动跳转到 `/mod/`。
- 页面免登录，打开即可查看。
- FastAPI 只使用 `mod_bi_reader` 查询，不提供公开写接口。
- 页面先显示内置模拟快照，再异步读取数据库实际汇总；异常时明确提示连接状态。
- API 使用 5 分钟进程内缓存，不增加 Redis 等外部组件。

## 三、功能范围

当前包含：

1. 领导驾驶舱和核心指标。
2. 中国地图及省级下钻。
3. 建设推广项目台账。
4. 单据、凭证、分录和集成链路分析。
5. 问题与风险中心。

当前不包含：

1. 登录、组织权限和单位数据权限。
2. 在线填报、审批及删除业务数据。
3. Excel 正式导入流程。
4. 生产系统接口和自动对账。

## 四、数据基线

- 模式：S（全部为虚构模拟数据）。
- 数据库：`mod_s`。
- 结构：24 张表、6 个分析视图。
- 总量：2,034,212 条。
- 单位：669 家。
- 凭证：195,000 张。
- 存储时区：UTC。
- 页面时区：Asia/Shanghai。
- 数据质量：凭证平衡错误、完整时间链错误、孤立关联和隐藏回车均为 0。

## 六、部署和恢复原则

- JPA 保存代码和文档，USA 是当前生产演示部署环境。
- 前端构建后同步到 USA，由 Nginx 直接提供静态文件。
- API 通过 Docker Compose 构建，设置自动重启、只读根文件系统、能力移除和健康检查。
- Nginx 变更必须先比较差异并执行配置语法检查，再热重载。
- DataEase/NocoDB 如需恢复，应使用保留的 Compose 配置启动，不重新初始化数据。
- 密钥只进入环境文件；日志、文档和提交不得出现密码。

## 七、隔离与禁止事项

- 不修改 MODO、`modo_db` 及其端口和配置。
- 不让匿名页面获得数据库写权限。
- 不直接向公网开放 FastAPI 或 MySQL 端口。
- IP 入口仅使用 HTTP；HTTPS 继续使用与证书匹配的域名入口。
- 未经批准不删除数据库、容器数据或其他云资源。
- 未经批准不创建 `mod_m`、`mod_p` 或新的 OCI 资源。
