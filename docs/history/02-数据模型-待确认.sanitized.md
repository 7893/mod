# MOD 数据模型

版本：1.1  
状态：V1 已实施，V2 目标模型部分确认（2026-08-30）

## 一、建模原则

- 先保存事实明细，再计算指标；页面中不得维护第二套手工数字。
- 单位、批次、状态、日期等维度统一编码。
- 进度采用“当前状态 + 历史快照”，同时支持看当前和看趋势。
- 业务单据、凭证及其关系分别保存，不能假定始终一单一证。
- 期初数据独立管理，不伪装成日常业务单据。
- 所有人工维护表包含来源、维护人、更新时间和版本信息。

## 三、关键业务关系

```text
推广批次 1 ── N 单位上线状态
单位     1 ── N 建设任务/数据准备/问题风险数量快照
单位     1 ── N 业务单据
业务单据 N ── N 会计凭证
会计凭证 1 ── N 凭证分录
单位     1 ── N 状态快照
来源批次 1 ── N 导入记录
```

## 四、建议状态字典

### 单位推广状态

`未启动` → `准备中` → `具备双轨条件` → `双轨运行中` → `已上线` → `稳定运行`

旁路状态：`暂缓`、`不具备条件`。

### 建设任务状态

`未开始`、`进行中`、`待确认`、`已完成`、`暂缓`、`取消`。

### 数据准备状态

`未收集`、`收集中`、`已提交`、`校验失败`、`待修正`、`校验通过`、`已导入`。

### 单据状态

`草稿`、`审批中`、`审批通过`、`已驳回`、`待生成凭证`、`处理完成`、`处理失败`。

### 凭证状态

`待生成`、`生成中`、`生成成功`、`生成失败`、`已集成`、`集成失败`、`已冲销`。

### 问题风险统计维度

- 阶段：`上线准备`、`上线后运行`。
- 问题类型：`Bug`、`需求`、`配置`、`数据`、`接口`、`操作`。
- 数量指标：`累计`、`新增`、`已解决`、`未解决`、`逾期`。
- 风险等级：`高`、`中`、`低`；只保存数量，不生成具体风险事项。
- 任一统计时点必须满足：各类型未解决数量之和等于未解决问题总数；累计数量等于已解决与未解决数量之和。

## 五、首批指标及口径建议

| 指标 | 建议口径 |
|---|---|
| 应推广单位数 | 纳入有效推广计划且未取消的单位去重数 |
| 已上线单位数 | 当前状态为“已上线”或“稳定运行”的单位去重数 |
| 上线完成率 | 已上线单位数 ÷ 应推广单位数 |
| 双轨运行单位数 | 当前状态为“双轨运行中”的单位去重数 |
| 数据准备完成率 | 已满足必填数据项的单位数 ÷ 应准备单位数 |
| 期初数据完成率 | 状态为“已导入”的单位数 ÷ 应准备期初数据单位数 |
| 建设任务完成率 | 已完成任务数 ÷ 未取消任务数 |
| 凭证生成成功率 | 生成成功凭证数 ÷ 已结束生成处理的凭证数 |
| 集成成功率 | 集成成功记录数 ÷ 已结束集成处理记录数 |
| 逾期事项数 | 未完成且当前时间超过截止时间的任务、问题、风险数 |
| 待协调风险数 | 未关闭且标记“需要领导协调”的风险数 |

说明：分母是否包含“处理中”、失败重试是否去重、单位状态以当前值还是统计时点为准，必须在最终口径中逐项确认。

## 六、S 模式数据规模

### 现行 V1 基线

现行 `mod_s` 的实际基线为 669 家单位、24 张表和 2,034,212 条记录，详见 `07-当前部署与运维基线.md`。本节原有规模建议不再作为下一轮生成目标。

### V2 目标原则

- 单位目标确定为 1,497 家。
- 推广分为八批，八批覆盖全部单位，每家单位只属于一个批次，不重复、不遗漏。
- 人员暂定 12,087 人，区分日常岗位和项目角色；各岗位和各单位人数采用自然的不规则分布。
- 建设任务目标约 4 万至 5 万项，不使用整百整千的机械数量，按单位类型、批次和阶段自然生成。
- 单据、凭证、双轨和历史快照继续保持百万级总体规模，准确数量及异常比例在最终生成前确认。
- V2 先在独立位置生成和核验，不直接覆盖现行 `mod_s`。
- 培训采用项目管理与关键用户、业务操作与财务处理、数据准备与系统管理、双轨运行与上线切换四类。
- 数据准备明确区分静态数据、期初数据和动态数据，并按批次使用不同的期初截止日与动态期间。
- 业务单据采用采购结算、费用报销、工程付款、资产处理、收入结算、资金收付六类。

模拟数据必须满足：

- 借贷金额平衡。
- 单据、审批、凭证、集成时间顺序合理。
- 存在一单一证、多单一证和一单多证。
- 存在少量可解释的失败、重试、延期和异常。
- 使用虚构组织名称，并在界面持续标记为模拟数据。
- 单位名称优先采用文雅、正面、庄重的文学地名、书院意象和山水文化词，搭配多样化组织形式；“中心”占比应保持很低。
- 人员姓名优先采用文人、学者、正面文学影视人物及具有书卷气的原创姓名。
- 单位和人员名称不得包含低俗、色情、反动、分裂、极端、邪教、犯罪、暴力或其他不适合领导展示的含义。
- 对单位和人员名称执行白名单、禁用词、负面语义及人工抽样四层检查。

## 七、已确认口径

1. “双轨运行中”不计入“已上线”，正式切换后才计入已上线单位数。
2. 推广进度主要按核算主体统计，同时保留组织单位维度。
3. 凭证生成成功率只统计已经结束处理的记录，排除排队中和处理中记录。
4. 期初数据按单位、期间和数据类型记录，再汇总形成单位完成率。
5. V1 的项目问题和风险分别建账；V2 改为按单位、批次、阶段和类型生成数量快照，不生成具体问题和风险文字。
6. 当前状态实时计算，历史趋势按日保存快照。
7. 单位关联标准地区编码，中国地图不得依赖自由文本地区名称计算。
