### 一、 关键指标业务口径与数学公式重定义

为避免凭证表内部状态与单据业务生成状态混淆，各核心指标的官方对账定义明确如下：

#### 1. 凭证生成成功率 (`voucher_generate_success_rate`)
- **业务定义**：单据发起生成凭证后，已成功生成有效会计凭证的单据比例（排除审批中、排队中和已驳回的单据）。
- **计算口径**：
  $$\text{凭证生成成功率} = \frac{\text{已成功生成凭证单据数 (处理完成)}}{\text{已结束生成处理的单据总数 (处理完成 + 生成失败)}} = \frac{165,417}{165,417 + 5,980} = \mathbf{96.51\%}$$
- **排除范围**：未进入生成环节的单据（`审批中` 12,072 张、`已驳回` 8,088 张、`待生成凭证` 8,055 张）。

#### 2. 接口集成成功率 (`integration_success_rate`)
- **业务定义**：已生成的会计凭证向外部总账或核算系统接口传输时，接口返回成功的比例。
- **计算口径**：
  $$\text{接口集成成功率} = \frac{\text{集成成功凭证数 (SUCCESS)}}{\text{已结束集成处理凭证总数 (SUCCESS + FAIL)}} = \frac{142,226}{142,226 + 8,007} = \mathbf{94.67\%}$$

#### 3. 推广上线进度指标
- **8月30日上线/稳定运行单位数 (`online_units`)**：**748 家**（全网上线完成率 **49.97%** = 748 / 1497）。
- **8月30日双轨运行单位数 (`dual_run_units`)**：**205 家**。
